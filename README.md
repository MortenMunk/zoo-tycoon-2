# Zoo Tycoon 2 - on NixOS!
My fiancé wants to play Zoo Tycoon 2 on my NixOS machine, so I wrote this Nix module to package and run it through Wine and DXVK.

## Disclaimer
I only wrote the Nix configuration files. I did not upload, host, or distribute the game archive itself, and I am not responsible for the downloaded files.

Pull requests with improvements are always welcome! If something isn't working for your setup, feel free to open an issue or let me know.
